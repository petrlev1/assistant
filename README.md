# RAG-ассистент

Интеллектуальная система для обработки запросов на основе Retrieval-Augmented Generation (RAG) с поддержкой GUI, веб-интерфейса и Telegram-бота.

## Возможности

- **Поиск релевантной информации**: Использует гибридный поиск (семантический + лексический BM25) для нахождения информации в базе знаний.
- **Генерация ответов**: Отправляет найденный контекст в LLM (OpenRouter) для генерации осмысленных ответов.
- **Поддержка форматов**: Обрабатывает данные из `.txt`, `.csv`, `.pdf`, `.docx`.
- **Множественные интерфейсы**:
  - Графический интерфейс (GUI) с вкладками настроек и чатом.
  - Веб-интерфейс (Flask).
  - Telegram-бот.

- **Настройка параметров**:
  - Количество релевантных фрагментов (`TOP_K`).
  - Вес семантического поиска (`ALPHA`).
  - Порог релевантности.
  - Ключи API для OpenRouter и Telegram.
- **Копирование/вставка в чате GUI**.
- **Переключение между несколькими LLM**.
- **Возможность отключения генерации (только поиск)**.

## Установка

1.  **Клонируйте репозиторий** (или скачайте ZIP-архив):
    ```bash
    git clone https://github.com/ваш-username/ваш-репозиторий.git
    cd ваш-репозиторий
    ```

2.  **Создайте и активируйте виртуальное окружение (рекомендуется)**:
    ```bash
    python -m venv venv
    # На Windows:
    venv\Scripts\activate
    # На Linux/macOS:
    source venv/bin/activate
    ```

3.  **Установите зависимости**:
    ```bash
    pip install openai sentence-transformers rank-bm25 numpy torch pathlib PyPDF2 python-telegram-bot python-docx flask
    ```

4.  **Настройте API ключи**:
    - Для OpenRouter: Получите API ключ на [OpenRouter](https://openrouter.ai/).
    - Для Telegram: Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.

## Использование

1.  **Поместите файлы базы знаний** в папку `Database`.

2. **Быстрый старт**  

```bash
# Клонировать репозиторий
git clone https://github.com/yourusername/assistant.git

# Перейти в директорию проекта
cd assistant

# Установить зависимости
pip install -r requirements.txt

# Запуск ассистента
python run_gui.py

**Запуск Telegram-бота**:
    - В GUI, во вкладке "Telegram", введите токен бота.
    - Нажмите "Применить", затем "Запустить бота".

## Структура проекта

- `rag_core.py`: Основная логика RAG-системы.
- `rag_gui.py`: Классы GUI.
- `run_gui.py`: Скрипт для запуска GUI.
- `web_app.py`: Логика Flask-приложения.
- `run_web.py`: Скрипт для запуска веб-сервера.
- `telegram_bot.py`: Логика Telegram-бота.
- `rag_settings.json`: Файл хранения настроек (создается автоматически).
- `Database/`: Папка для файлов базы знаний.
