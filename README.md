# 🤖 Интеллектуальный чат-бот с базой знаний

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-Free-green.svg)](LICENSE)

**Интеллектуальный чат-бот** с возможностью загрузки базы знаний в **любом формате**. Система на основе **Retrieval-Augmented Generation (RAG)** автоматически обрабатывает ваши документы и использует их для генерации точных ответов на вопросы.

> 💡 **Ключевая особенность:** Загрузите любые документы (PDF, DOCX, TXT, CSV, XLSX) в папку `Database/`, и бот автоматически извлечет из них информацию для ответов на вопросы.

## 🎯 Что это?

Это **умный чат-бот**, который:
- 📚 **Загружает базу знаний** из документов любого формата
- 🔍 **Ищет релевантную информацию** в ваших документах
- 💬 **Отвечает на вопросы** на основе загруженных данных
- 🖥️ **Работает через GUI, веб-интерфейс или Telegram**

## ✨ Возможности

### 📚 Загрузка базы знаний в любом формате

**Поддерживаемые форматы:**
- 📄 **Текстовые файлы** — `.txt`
- 📊 **Таблицы** — `.csv`, `.xlsx`, `.xls`
- 📑 **Документы** — `.pdf`, `.docx`
- 🔄 **Автоматическая обработка** — просто поместите файлы в папку `Database/`

**Как это работает:**
1. Поместите ваши документы в папку `Database/`
2. При запуске система автоматически извлечет текст из всех файлов
3. Создаст векторные представления (эмбеддинги) для быстрого поиска
4. Готово! Бот может отвечать на вопросы на основе ваших документов

### 🔍 Интеллектуальный поиск

- **Семантический поиск** — понимает смысл запросов, а не только ключевые слова
- **Лексический поиск (BM25)** — точное совпадение терминов
- **Гибридный поиск** — комбинация обоих методов для лучших результатов

### 🤖 Генерация ответов

- Использует **LLM модели** через OpenRouter API
- Формирует ответы на основе найденной информации
- Указывает источники информации

### 🖥️ Множественные интерфейсы

- **Графический интерфейс (GUI)** — удобное управление и чат
- **Веб-интерфейс** — доступ через браузер
- **Telegram-бот** — интеграция с мессенджером

## 🚀 Установка
Предварительные требования
Python 3.8 или выше
pip (менеджер пакетов Python)
~2GB свободного места (для модели эмбеддингов)

### Шаг 1: Клонирование репозитория
1. `git clone https://github.com/petrlev1/assistant.git`
2. `cd assistant`

### Шаг 2: Создание виртуального окружения
#### Windows:
1. Создание: `python -m venv venv`
2. Активация:
   - bash: `venv\Scripts\activate.bat`
   - powershell: `.\venv\Scripts\Activate.ps1`
#### Linux/macOS: 
1. Создание: `python3 -m venv venv`
2. Активация: `source venv/bin/activate`
#### Деактивация виртуального окружения
`deactivate`

### Шаг 3: Установка зависимостей
`pip install -r requirements.txt`

### Шаг 4: Подготовка базы знаний
- Создайте папку Database (если её нет): mkdir Database
- Поместите ваши документы в папку Database/

### Шаг 5: Настройка API ключей
OpenRouter API (обязательно):
1. Зарегистрируйтесь на OpenRouter
2. Получите API ключ
3. Добавьте в настройки (см. раздел "Использование")
4. Telegram Bot (опционально):
Создайте бота через @BotFather.
Получите токен бота

## Использование
### Быстрый старт
- Загрузите документы в базу знаний:
- Поместите ваши файлы в папку Database/
- Запустите GUI: `python run_gui.py`

#### Настройте API ключ:
Во вкладке "Настройки" введите ключ OpenRouter
Нажмите "Применить"
Начните общаться:
Перейдите во вкладку "Чат"
Задайте вопрос на основе ваших документов
Получите ответ!

### Графический интерфейс (GUI): `python run_gui.py`
#### Возможности:
- ⚙️ Настройка параметров поиска
- 🔑 Управление API ключами
- 💬 Интерактивный чат с ботом
- 🔄 Перезагрузка базы знаний
- 🤖 Запуск Telegram-бота

### Веб-интерфейс: `python run_web.py`
- Откройте в браузере:
- Локально: http://localhost:8000
- В сети: http://<ваш-ip>:8000

#### Telegram-бот
- Запустите GUI: python run_gui.py
- Перейдите во вкладку "Telegram"
- Введите токен бота
- Нажмите "Применить" → "Запустить бота"
#### Команды бота:
/start — начальное сообщение
/help — помощь по использованию
/stats — статистика базы знаний

Основные библиотеки

openai — клиент для OpenRouter API
python-telegram-bot — Telegram Bot API

⚙️ Настройка
Параметры поиска
Настраиваются через GUI или rag_settings.json:
{    "search_top_k": 30,              // Сколько фрагментов искать    "search_alpha": 0.7,             // Вес семантического поиска (0-1)    "relevance_threshold": 0.1,      // Минимальная релевантность    "max_context_fragments": 100     // Максимум фрагментов в контексте}
Флаги управления
disable_openrouter_models — отключить LLM (только поиск)
disable_hybrid_search — отключить гибридный поиск
disable_knowledge_base_search — работать только через LLM
