<h1>RAG система</h1>
Система производит поиск релевантной информации по базе знаний, после чего ИИ выдает ответ в соответствии с найденной информацией.
<br>
Функции:<br>
1. Поиск релевантной информации<br>
2. Обработка релевантной информации при помощи ИИ<br>
3. Чат бот со своей базой знаний<br>
4. Подключение чат бота к Телеграм.
<br><br>
Функции:<br>
1. Подключение мессенджеров<br>
2. Веб-версия чат бота<br>
3. Тонкая настройка RAG системы.
