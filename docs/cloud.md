# ☁️ Облако для файлов

Вместе с RAG-системой каждому пользователю доступно **облако** — личное хранилище файлов на [cloud.ragstone.ru](https://cloud.ragstone.ru). Отдельный аккаунт не нужен: вход тот же, что на ragstone.ru, а диск **«Мои файлы»** — это папка вашей базы знаний.

## Как войти

Способы два, пароль один:

1. **Из кабинета** — кнопка **«☁️ Мои файлы»** в шапке чата. Облако откроется сразу, повторно вводить пароль не нужно.
2. **Напрямую** — откройте [cloud.ragstone.ru](https://cloud.ragstone.ru) и войдите тем же логином и паролем, что на ragstone.ru.

Оба способа ведут в один и тот же диск «Мои файлы».

## Что можно делать

| Действие | Как это работает |
|---|---|
| **Загрузить файлы** | Кнопка загрузки в шапке или перетаскивание файлов в окно. Можно загружать по одному и пакетом |
| **Создать папку** | Кнопка «Новая папка». Внутри папок можно создавать вложенные |
| **Переименовать, перенести** | Меню файла: имя меняется, файл переносится в другую папку |
| **Скачать** | Клик по файлу или пункт «Скачать» в меню |
| **Удалить** | Меню «Удалить»: показывается прогресс, удаление можно отменить |
| **Найти файл** | Строка поиска: ищет **по содержимому** документов и по названиям файлов и папок |
| **Поделиться** | «Ссылка» даёт публичную ссылку на файл; её можно закрыть в списке ссылок |

Открывать и скачивать файлы можно с компьютера, планшета и телефона.

## Файлы сразу попадают в базу знаний

Диск «Мои файлы» — та же папка, из которой ассистент берёт знания. Поэтому:

- загрузили файл в облако → он появился в **«Моих документах»** в кабинете ragstone, и ассистент отвечает по его содержимому;
- переименовали, перенесли в папку или удалили → список документов и ответы бота обновляются;
- загрузили файл с тем же именем → облако предложит **заменить** его: версия обновляется, бот отвечает по новому содержимому, дубль в базе знаний не появляется;
- поправили файл в обход облака (скопировали по сети, изменили на сервере) → изменения подхватываются при открытии папки в облаке.

Переиндексация идёт в фоне: обычно несколько секунд, на большой базе — до минуты. Если ответ всё ещё по старой версии, подождите и задайте вопрос ещё раз.

## Сколько места

- **1 ГБ на пользователя** — общий лимит на всю папку «Мои файлы», включая вложенные папки.
- Занятое место и лимит показаны в шапке облака.
- Если места не хватает, загрузка не выполняется: система сообщает, сколько занято из лимита, и не сохраняет ни один файл из пакета. Освободите место — удалите ненужные файлы.

## Что видно пользователю

- Доступны **только свои файлы** — папка пользователя изолирована на сервере, а не просто скрыта в интерфейсе.
- Служебные разделы (диагностика дисков, полный индекс поиска, обход всего сервера) есть только у владельца сервиса — в обычном аккаунте их нет.
- Ссылки, которые вы создали, видны вам в списке ссылок; открыть файл по ссылке может любой, у кого она есть.

## Какие файлы попадают в ответы бота

В базу знаний идут форматы из раздела [«Документы и база знаний»](/docs/documents): PDF, DOCX, XLSX, CSV, TXT и картинки (с них распознаётся текст и составляется описание). Остальные файлы — архивы, видео, программы — в облаке хранятся и скачиваются, но фрагментов в базу знаний не добавляют.

Прайс-листы, загруженные через облако, работают так же, как загруженные в кабинете: ассистент отвечает точными ценами (см. [«Загрузка прайс-листа»](/docs/prices)).

## Частые вопросы

**Не вижу кнопку «☁️ Мои файлы».** Кнопка есть в шапке чата после входа в систему.

**Облако просит пароль.** При прямом входе на cloud.ragstone.ru нужны те же логин и пароль, что на ragstone.ru. Через кнопку «Мои файлы» пароль не спрашивается.

**«Не хватает места».** Лимит 1 ГБ исчерпан: удалите лишние файлы, занятое место видно в шапке облака.

**Файл загружен, а бот про него не знает.** Подождите несколько секунд — идёт переиндексация. Если формат не поддерживается (архив, видео), в базу знаний файл не попадёт.

**Изменил файл, а ответы старые.** Откройте «Мои файлы»: при открытии папки система сверяет файлы с базой знаний и обновляет изменённые.

**Файл не находится поиском.** В облаке поиск по содержимому работает для текстовых форматов и документов (PDF, Word, Excel, CSV, TXT); картинки и архивы находятся по названию. Поиск идёт в пределах папки, которую вы сейчас смотрите, — поднимитесь на уровень выше, чтобы искать по всей своей папке.
